## Featured Project

### Seoul Subway Ridership and Bike-Sharing Usage Analysis

This project explores whether areas with higher subway ridership also tend to have greater usage of Seoul's public bike-sharing service, Ttareungi.

The analysis brings together datasets with different sources and units, standardizes station and location information, aggregates observations into comparable groups, and examines their relationship through exploratory analysis and visualization. The interpretation distinguishes correlation from causation and documents the limits of the available data.

**Tools:** Python, Pandas, exploratory data analysis, data visualization

[View the analysis repository](https://github.com/beckspeca/yeardreamschool6th_AnalyzeMiniProject)

## Analysis Workflow

1. **Define the question** — Identify the decision context and establish a testable analytical question.
2. **Understand the data** — Review sources, units, missing values, data types, and potential bias.
3. **Prepare and explore** — Clean, transform, aggregate, and visualize the data to identify meaningful patterns.
4. **Validate and communicate** — Consider alternative explanations, state limitations, and translate findings into clear insights.
