## 1. 경사하강법이란?

머신러닝 모델은 데이터를 보고 스스로 규칙을 찾아간다. 예를 들어 공부 시간과 시험 점수의 관계를 학습한다고 해보자.

공부 시간이 많을수록 점수가 높아진다는 관계를 단순하게 표현하면 다음과 같은 직선 모델을 만들 수 있다.

```text
y = wx + b
```

여기서 `x`는 공부 시간, `y`는 시험 점수, `w`는 기울기, `b`는 절편이다. 머신러닝 모델이 학습한다는 것은 결국 데이터에 가장 잘 맞는 `w`와 `b`를 찾는 과정이라고 볼 수 있다.

이때 사용하는 대표적인 방법이 **경사하강법(Gradient Descent)**이다.

> 경사하강법은 손실 함수의 값이 작아지는 방향으로 파라미터를 조금씩 이동시키는 최적화 방법이다. 쉽게 말하면, 현재 위치에서 오차가 줄어드는 방향을 찾아 조금씩 내려가는 방식이다.

## 2. 손실 함수: 모델이 얼마나 틀렸는가?

모델이 예측한 값과 실제 값이 얼마나 차이 나는지 계산해야 한다. 이 차이를 수치로 표현한 것이 **손실 함수(Loss Function)**다.

회귀 문제에서는 보통 평균제곱오차, 즉 **MSE**를 많이 사용한다.

```text
J(θ) = (1/n) Σ(ŷᵢ - yᵢ)²
```

코드로 옮기면 다음과 같다.

```python
loss = mean((y_pred - y_true) ** 2)
```

오차를 그냥 더하지 않고 제곱하는 이유는 양수와 음수가 서로 상쇄되는 문제를 막기 위해서다. 예를 들어 어떤 예측은 실제보다 10 높고, 어떤 예측은 실제보다 10 낮으면 단순 합계는 0이 된다. 하지만 실제로는 둘 다 틀린 예측이다. 그래서 차이를 제곱해서 오차의 크기를 반영한다.

## 3. 경사하강법의 핵심 아이디어

경사하강법의 핵심은 다음 한 줄로 정리할 수 있다.

```text
θₜ₊₁ = θₜ - α · ∇J(θₜ)
```

| 기호 | 의미 |
| --- | --- |
| `θₜ` | 현재 파라미터(t번째 지점) |
| `θₜ₊₁` | 다음 파라미터(t+1번째 지점) |
| `α` | 학습률(learning rate) |
| `∇J(θₜ)` | 손실 함수의 기울기(gradient) |

기울기 `∇J(θₜ)`는 미분으로 정의된다.

```text
∇J(θₜ) = ∂J / ∂θₜ
```

기울기가 **양수**라면 왼쪽, 즉 파라미터를 감소시키는 방향으로 이동하고 기울기가 **음수**라면 오른쪽, 즉 파라미터를 증가시키는 방향으로 이동한다. 이렇게 하면 손실 함수의 값이 점점 작아지는 방향으로 이동할 수 있다.

여기서 중요한 값이 **학습률(learning rate)** `α`다. 학습률은 한 번에 얼마나 이동할지를 정하는 값이다. 너무 크면 최솟값을 지나쳐서 손실이 튈 수 있고, 너무 작으면 학습이 너무 느려진다.

## 4. NumPy로 간단한 데이터 만들기

먼저 공부 시간과 시험 점수 데이터를 만들어보자.

```python
import numpy as np
import pandas as pd

x = np.array([1, 2, 3, 4, 5])
y = np.array([2, 4, 6, 8, 10])
```

이 데이터는 사실상 `y = 2x` 관계를 가진다. 우리가 만들 모델은 이 관계를 학습해서 `w`가 2에 가까워지도록 만드는 것이 목표다.

처음에는 `w`와 `b`를 아무 값으로 시작한다.

```python
w = 0
b = 0
```

현재 모델은 다음과 같다.

```python
y_pred = 0 * x + 0
```

즉 모든 예측값이 0이다. 실제 값 `[2, 4, 6, 8, 10]`과 비교하면 오차가 크다.

## 5. NumPy로 경사하강법 구현하기

이제 경사하강법을 코드로 구현해보자.

```python
import numpy as np
import pandas as pd

# 데이터
x = np.array([1, 2, 3, 4, 5])
y = np.array([2, 4, 6, 8, 10])

# 초기값
w = 0.0
b = 0.0

# 학습률과 반복 횟수
learning_rate = 0.01
epochs = 100

# 학습 과정 저장
history = []
n = len(x)

for epoch in range(epochs):
    # 1. 예측
    y_pred = w * x + b

    # 2. 손실 계산
    loss = np.mean((y_pred - y) ** 2)

    # 3. 기울기 계산
    dw = (2 / n) * np.sum((y_pred - y) * x)
    db = (2 / n) * np.sum(y_pred - y)

    # 4. 파라미터 업데이트
    w = w - learning_rate * dw
    b = b - learning_rate * db

    # 5. 학습 과정 기록
    history.append({"epoch": epoch, "w": w, "b": b, "loss": loss})

history_df = pd.DataFrame(history)
history_df.head()
```

코드 속 `dw`, `db`는 각각 `w`, `b`에 대한 손실 함수의 기울기 `∇J`를 의미한다. NumPy는 배열 연산을 빠르게 처리하는 역할을 하고, Pandas는 학습 과정을 표 형태로 저장하고 확인하는 데 사용한다.

## 6. 학습 결과 확인하기

학습이 진행되면 `w`는 점점 2에 가까워지고, 손실 값은 점점 줄어든다.

```python
history_df.tail()
```

예상되는 결과는 다음과 같은 흐름이다.

- epoch가 증가할수록
- loss는 감소하고
- w는 2에 가까워진다

그래프로 확인하면 더 직관적이다.

```python
import matplotlib.pyplot as plt

plt.plot(history_df["epoch"], history_df["loss"])
plt.xlabel("Epoch")
plt.ylabel("Loss")
plt.title("Loss 감소 과정")
plt.show()
```

손실 그래프가 아래로 내려간다면 모델이 점점 데이터를 잘 설명하고 있다는 뜻이다.

## 7. 경사하강법을 직관적으로 이해하기

경사하강법은 산에서 가장 낮은 지점을 찾아 내려가는 과정과 비슷하다.

현재 위치에서 바닥이 어느 방향으로 기울어져 있는지 확인한다. 그리고 기울기가 낮아지는 방향으로 한 걸음 이동한다. 이 과정을 여러 번 반복하면 점점 낮은 지점에 도달한다.

머신러닝에서는 이 "높이"가 손실 값이다. 즉, 손실이 낮을수록 모델의 예측이 실제 데이터와 더 비슷하다는 뜻이다.

정리하면 다음과 같다.

```text
현재 모델로 예측한다 → 실제값과 비교해서 오차를 계산한다 → 오차가 줄어드는 방향을 찾는다 → w와 b를 조금 수정한다 → 다시 예측한다 → 이 과정을 반복한다
```

## 8. 학습률이 중요한 이유

학습률이 너무 작으면 손실은 안정적으로 줄어들지만 학습 속도가 느리다.

```python
learning_rate = 0.0001
```

반대로 학습률이 너무 크면 한 번에 너무 많이 이동해서 최솟값을 지나칠 수 있다.

```python
learning_rate = 1.0
```

그래서 경사하강법에서는 학습률 `α`를 적절히 조절하는 것이 중요하다. 머신러닝 모델이 잘 학습되지 않을 때는 데이터 문제뿐 아니라 학습률 설정 문제일 수도 있다.

## 9. Pandas로 학습 과정 분석하기

학습 기록을 DataFrame으로 저장하면 각 epoch마다 `w`, `b`, loss가 어떻게 변했는지 쉽게 확인할 수 있다.

```python
history_df.describe()
```

또는 손실이 가장 낮았던 시점을 찾을 수도 있다.

```python
history_df.loc[history_df["loss"].idxmin()]
```

이처럼 Pandas는 모델 자체를 학습시키는 도구라기보다는, 학습 과정에서 나온 결과를 정리하고 분석하는 데 유용하다. NumPy는 계산을 담당하고, Pandas는 결과를 표로 정리하는 역할을 한다고 이해하면 좋다.

## 10. 마무리

경사하강법은 머신러닝에서 모델이 스스로 더 나은 방향으로 이동하도록 도와주는 핵심 알고리즘이다.

```text
θₜ₊₁ = θₜ - α · ∇J(θₜ)
```

이번 글에서는 복잡한 머신러닝 라이브러리를 사용하지 않고 NumPy와 Pandas만으로 경사하강법의 기본 구조를 구현해봤다.

핵심은 다음과 같다.

1. 예측값을 계산한다.
2. 실제값과 비교해 손실을 계산한다.
3. 손실이 줄어드는 방향, 즉 기울기를 계산한다.
4. 파라미터를 조금씩 수정한다.
5. 이 과정을 반복한다.

경사하강법을 이해하면 선형회귀, 로지스틱 회귀, 신경망 학습까지 이어지는 머신러닝의 기본 구조를 훨씬 쉽게 이해할 수 있다.
