개발을 하다 보면 어제 해결한 문제를 오늘 다시 검색하게 됩니다. 이 블로그는 그런 순간을 줄이기 위해 시작했습니다.

## 무엇을 기록할까

- 문제를 해결하기 위해 시도했던 과정
- 새로 배운 기술을 실제 프로젝트에 적용한 경험
- 다시 같은 선택을 한다면 다르게 하고 싶은 것

완성된 정답만 보여주기보다, 답을 찾아가는 과정까지 솔직하게 남기겠습니다.

```ts
const principle = '배운 것은 내 언어로 다시 설명한다';
console.log(principle);
```

작은 기록이 쌓여 더 나은 개발자가 되는 과정을 이곳에서 공유하겠습니다.
