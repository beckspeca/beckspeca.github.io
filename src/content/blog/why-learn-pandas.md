이어드림 스쿨 6기를 시작하고 데이터 분석을 시작하면 가장 먼저 마주치는 것은 복잡한 수식이나 머신러닝 모델이 아니라, 대부분 표 형태의 데이터다. 예를 들어 
- chinook.db
- books.db 
- titanic.db
위와 같은 데이터 모두 행과 열로 이루어진 구조를 가진다.

이런 데이터를 파이썬에서 편하게 불러오고, 확인하고, 수정하고, 요약하기 위해 사용하는 대표적인 라이브러리가 바로 Pandas다.

## 1. Pandas 사용방법 
Pandas는 Python에서 데이터를 다루기 위한 라이브러리다. 쉽게 말하면, 엑셀처럼 생긴 데이터를 코드로 다룰 수 있게 해주는 도구라고 볼 수 있다.

엑셀에서는 마우스로 필터를 걸고, 평균을 구하고, 필요한 열만 선택한다. Pandas에서는 이런 작업을 코드로 처리한다.

![](https://velog.velcdn.com/images/backspace/post/079802c9-0bad-4b08-b921-2c9a56c9f2d4/image.png)

사용코드 

```python 
import pandas as pd
```

## 2. Pandas가 필요한 이유

데이터 분석 과정은 보통 다음 흐름으로 진행된다.
`데이터 불러오기 → 데이터 확인 → 데이터 정리 → 데이터 변환 → 데이터 요약 → 분석/시각`

가장 날것의 데이터 => Raw Data 를 편집 하기 편하게 만드는 도구인 셈이다. 


## 3. Pandas의 기본 구조

Pandas를 이해하려면 두 가지 개념을 먼저 알아야 한다.

### Series

Series는 1차원 데이터다. 쉽게 말하면 표에서 하나의 열이라고 생각하면 된다.(정확하지 않다.)

```python
import pandas as pd

age = pd.Series([20, 21, 22, 23])
print(age)
```
이런 식으로 불러오면 나이 데이터만 불러오게 되는 것이다. 
 
```text
0    20
1    21
2    22
3    23
dtype: int64
```

### DataFrame
DataFrame은 여러 개의 Series가 모여 만들어진 2차원 구조이다. 

```python
df = pd.DataFrame({
    "name": ["민수", "지영", "철수"],
    "age": [21, 22, 20],
    "score": [85, 90, 78]
})

print(df)
```
이런식 으로 불러오게 되면 

```text
  name  age  score
0   민수   21     85
1   지영   22     90
2   철수   20     78
```
처럼 "이름","나이", "점수" 등을 복합적으로 가져오는  2차원의 복합 데이터이다. 


## 4. Pandas를 배운다는 것의 의미
Pandas를 배운다는 것은 단순히 함수 이름을 외우는 것이 아니다.
데이터와 소통하는 하나의 새로운 언어를 배우는 것이고, 언어를 배운다는 것은 새로운 세계를 볼 수 있는 수단이기 때문에 데이터와의 소통에 불편함이 없으려면 가장 기본적인 Pandas를 탄탄하게 배워야 한다.
