데이터 분석을 시작하면 가장 먼저 마주치는 것은 복잡한 수식이나 머신러닝 모델이 아니라 대부분 표 형태의 데이터다. 데이터베이스의 테이블, CSV 파일, 엑셀 문서는 모두 행과 열로 이루어진 구조를 가진다.

이런 데이터를 Python에서 불러오고, 확인하고, 수정하고, 요약하기 위해 사용하는 대표적인 라이브러리가 **Pandas**다.

## Pandas는 어떤 도구일까

Pandas는 Python에서 데이터를 다루기 위한 라이브러리다. 쉽게 말하면 엑셀처럼 생긴 데이터를 코드로 다룰 수 있도록 해주는 도구라고 볼 수 있다.

엑셀에서는 마우스로 필터를 걸고 평균을 구하거나 필요한 열을 선택한다. Pandas에서는 같은 작업을 코드로 처리한다.

```python
import pandas as pd
```

## 데이터 분석에서 Pandas가 필요한 이유

데이터 분석은 보통 다음 흐름으로 진행된다.

```text
데이터 불러오기 → 확인 → 정제 → 변환 → 요약 → 분석·시각화
```

현실의 원본 데이터는 바로 분석하기 어려운 경우가 많다. 값이 비어 있거나 형식이 서로 다르고, 분석에 필요하지 않은 정보가 섞여 있기도 한다. Pandas는 이런 원본 데이터를 분석 가능한 형태로 만드는 과정에 유용하다.

## Pandas의 기본 구조

Pandas를 이해하려면 `Series`와 `DataFrame`이라는 두 가지 구조를 먼저 알아야 한다.

### Series

Series는 하나의 축을 가진 1차원 데이터다. 표의 한 열과 비슷하게 이해할 수 있다.

```python
age = pd.Series([20, 21, 22, 23])
print(age)
```

```text
0    20
1    21
2    22
3    23
dtype: int64
```

각 값에는 순서를 나타내는 인덱스가 함께 존재한다.

### DataFrame

DataFrame은 여러 Series가 모인 2차원 표 구조다.

```python
df = pd.DataFrame({
    "name": ["민수", "지영", "철수"],
    "age": [21, 22, 20],
    "score": [85, 90, 78]
})

print(df)
```

```text
  name  age  score
0   민수   21     85
1   지영   22     90
2   철수   20     78
```

서로 관련된 여러 정보를 행과 열로 묶어 분석할 수 있다. 실제 데이터 분석에서 가장 자주 다루게 되는 형태다.

## Pandas를 배운다는 것

Pandas를 배운다는 것은 단순히 함수 이름을 외우는 일이 아니다. 데이터를 관찰하고 필요한 형태로 변환하며, 질문에 답하기 위한 분석 구조를 만드는 법을 배우는 과정이다.

도구의 문법뿐 아니라 다음 질문을 함께 고민해야 한다.

- 각 행과 열은 무엇을 의미하는가?
- 누락되거나 잘못된 값은 없는가?
- 어떤 단위로 비교해야 하는가?
- 이 데이터만으로 결론을 내려도 되는가?

Pandas는 이런 질문을 실제 데이터에 적용하게 해주는 데이터 분석의 기본 도구다.
